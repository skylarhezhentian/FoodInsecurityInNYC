# Upstream source snapshots

This directory contains the public-data inputs read by the recovered preprocessing programs, together with their saved reference outputs. The archive is approximately 28 MB including source code and figures. [The preprocessing guide](../../research/preprocessing/README.md) explains the offline replay; [the manifest](../../research/preprocessing/manifest.json) records every included file and any sanitization.

| Snapshot | Source and role |
| --- | --- |
| `foodhelp/food_help_programs.{csv,geojson}` | 528 provider records for access analysis, associated with [NYC FoodHelp](https://finder.nyc.gov/foodhelp/locations) and [HRA food assistance](https://www.nyc.gov/site/hra/help/food-assistance.page). The exact export request and acquisition date were not recovered. |
| `foodhelp/efap_pfred_programs.{csv,geojson}` | 842 EFAP provider records used by the routing instance builder; same source family and acquisition gap. |
| `foodhelp/analysis/data/community_districts.geojson` | [NYC community districts, dataset `5crt-au7u`](https://data.cityofnewyork.us/City-Government/Community-Districts/5crt-au7u), as identified by the recovered code. |
| `foodhelp/analysis/data/snap_cd_all_months.json` | [SNAP recipients by community district, dataset `5awp-wfkt`](https://data.cityofnewyork.us/Social-Services/SNAP-Recipients-by-Community-District/5awp-wfkt), as identified by the recovered code. The earlier map selects the latest month present in this saved file. |
| `foodhelp/analysis/data/cd_population.json` | [Community district population, dataset `xi7c-iiu2`](https://data.cityofnewyork.us/City-Government/New-York-City-Population-By-Community-Districts/xi7c-iiu2), as identified by the recovered code. The earlier map uses 2010 population. |
| `foodhelp/analysis/data/nta_2020.geojson` | [2020 NTA boundaries, NYC Department of City Planning](https://data.cityofnewyork.us/City-Government/2020-Neighborhood-Tabulation-Areas-NTAs-/9nt8-h7nd). |

| `foodhelp/council_data/input/Neighborhood Prioritization Map 2025.csv` | Food-insecurity estimates associated with the [NYC Emergency Food Supply Gap and Neighborhood Prioritization work](https://www.nyc.gov/site/foodpolicy/programs/supply-gap.page), [2025 map](https://public.tableau.com/app/profile/claire.reynolds6296/viz/SupplyGap2025/Dashboard1), and [public dataset](https://data.cityofnewyork.us/City-Government/Emergency-Food-Supply-Gap/4kc9-zrs2/about_data). The exact CSV export request was not recovered. |
| `foodhelp/council_data/input/nyc_decennialcensusdata_2010_2020_change.xlsx` | [NYC DCP 2010/2020 Census population workbook](https://www.nyc.gov/assets/planning/download/office/planning-level/nyc-population/census2020/nyc_decennialcensusdata_2010_2020_change.xlsx?r=3). Programs read the `2010, 2020, and Change` sheet with header row 4, selecting `NTA2020` or `CT2020` geography. |
| `foodhelp/analysis/output/` | Saved maps and numerical tables from the recovered local project. These are comparison targets, not inputs substituted for recalculation. |
| `donor_model/data/nyc_boroughs.geojson` | NYC borough boundary snapshot for donor-study figures. Its exact export request and acquisition date were not recovered. |
| `donor_model/data/per_donor_estimates.csv`, `results.json` | Saved modeled donor outputs. The numerical inputs are encoded in the archived `donor_model/src/data.py`; see the qualification below. |

The donor study cites the [City Harvest food-donor roster](https://www.cityharvest.org/food-donors/) and Food Bank For New York City FY2025 audited financials. Twelve published donor amounts are encoded as anchors; the remainder is modeled using category priors and reconciliation assumptions. The precise downloaded source documents and extraction dates were not recovered. The archive retains the original citations without representing these inputs as newly verified or measured pickup supplies.

The data is included for research transparency. Government and third-party source terms continue to apply; the project code license does not grant new rights over source data, marks, or names. No standalone redistribution license was recovered for each local export. Provider organization phone numbers, editor/creator usernames, and unused free-text notes were removed. The Census workbook's creator/editor metadata was also removed, while every other ZIP member, including all worksheets and source attribution, remains byte-identical. No contact directory, private correspondence, credentials, environment files, or user home paths are included.

The routing travel cache lives separately in `data/model/`. For its OpenStreetMap/OSRM attribution and historical alignment limitations, see [the model data guide](../README.md). No routing service or new source download is used by the offline preprocessing replay.
